# shipschematic-skills-public

Public skill packs. One repo, one pack per job, one installer per pack.

## Packs

| Pack | Package | Skills |
|---|---|---|
| `packs/design-judges` | `@shipschematic/design-judges` | book-design-judge, cover-judge, page-judge, carousel-judge, thumbnail-judge |

## Skills

| Skill | Use for | Install |
|---|---|---|
| `book-design-judge` | Print book cover or interior page, 7×9.25 in, two-ink | `npx @shipschematic/design-judges --only book-design-judge` |
| `cover-judge` | A5 screen-edition book cover, HTML and PDF | `npx @shipschematic/design-judges --only cover-judge` |
| `page-judge` | A5 screen-edition book page, type, figures, accessibility | `npx @shipschematic/design-judges --only page-judge` |
| `carousel-judge` | LinkedIn, Instagram, and X carousels | `npx @shipschematic/design-judges --only carousel-judge` |
| `thumbnail-judge` | YouTube thumbnail, 1280×720, mobile-first | `npx @shipschematic/design-judges --only thumbnail-judge` |

## Install

Published on npmjs. No registry authentication needed.

```bash
npx @shipschematic/design-judges
```

Installs all five skills into `./.opencode/skills`.

Targets:

```bash
npx @shipschematic/design-judges                   # ./.opencode/skills
npx @shipschematic/design-judges --global          # ~/.config/opencode/skills
npx @shipschematic/design-judges --claude          # ./.claude/skills
npx @shipschematic/design-judges --global --claude # ~/.claude/skills
npx @shipschematic/design-judges --list
npx @shipschematic/design-judges --only cover-judge,page-judge
```

`--force` overwrites existing skills. Without it, existing skills are skipped.

## Layout

```
packs/
  design-judges/
    package.json
    bin/install.js        generated by `npm run sync:bin`
    skills/<skill>/SKILL.md
scripts/
  install.js              installer source
  sync-bin.js             copies the installer into each pack
  list.js
.github/workflows/        CI and npm release
.changeset/               versioning and changelogs
```

Add a pack:

1. Create `packs/<name>/skills/<skill>/SKILL.md`.
2. Add `packs/<name>/package.json` with a unique `@shipschematic/<name>` name.
3. Run `npm run sync:bin`.
4. Add the pack to the table above.

## Release

Releases are CI-only. The package publishes to npmjs from GitHub Actions with Trusted Publishing (OIDC). No long-lived npm token is stored.

Add a changeset:

```bash
npx changeset
```

Merge the PR, merge the Version Packages PR, and the Release workflow publishes to npmjs with provenance, tags the package, and creates a GitHub release.

Never run `npm publish` by hand. Versions come from Changesets.

See [RELEASING.md](RELEASING.md) for the full checklist and troubleshooting.
