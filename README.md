# shipschematic-skills-public

Public skill packs. One repo, one pack per job, one installer per pack.

## Packs

|---|---|---|
| `packs/design-judges` | `@shipschematic/design-judges` | book-design-judge, cover-judge, page-judge, carousel-judge, thumbnail-judge |

## Install

The package lives on GitHub Packages, which requires authentication even for public packages. Add this to `.npmrc` and export a token with `read:packages`:

```
@shipschematic:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

```bash
export GITHUB_TOKEN=<token with read:packages>
npx @shipschematic/design-judges
```

Targets:

```bash
npx @shipschematic/design-judges                   # ./.opencode/skills
npx @shipschematic/design-judges --global          # ~/.config/opencode/skills
npx @shipschematic/design-judges --claude          # ./.claude/skills
npx @shipschematic/design-judges --global --claude # ~/.claude/skills
npx @shipschematic/design-judges --list
npx @shipschematic/design-judges --only cover-judge,page-judge
```

`--force` overwrites existing skills. Without it, existing skills are skipped.

## Layout

```
packs/
  design-judges/
    package.json
    bin/install.js        generated by `npm run sync:bin`
    skills/<skill>/SKILL.md
scripts/
  install.js              installer source
  sync-bin.js             copies the installer into each pack
  list.js
.github/workflows/        CI and GitHub Packages release
.changeset/               versioning and changelogs
```

Add a pack:

1. Create `packs/<name>/skills/<skill>/SKILL.md`.
2. Add `packs/<name>/package.json` with a unique `@shipschematic/<name>` name.
3. Run `npm run sync:bin`.
4. Add the pack to the table above.

## Release

Releases are CI-only. The package publishes to GitHub Packages with the workflow `GITHUB_TOKEN`; no long-lived npm token is stored.

First publish:

```bash
gh workflow run release.yml
```

For later releases, add a changeset:

```bash
npx changeset
```

Merge the PR, merge the Version Packages PR, and the Release workflow publishes, tags, and creates a GitHub release.

Never run `npm publish` by hand. Versions come from Changesets.

See [RELEASING.md](RELEASING.md) for the full checklist and troubleshooting.

npmjs publishing is disabled while the npm account is suspended. The restore checklist is in [NPM_RESTORE.md](NPM_RESTORE.md).
